# Laços em Palavra

Diário do estudo bíblico da família.

A página reúne o versículo e a pergunta de cada encontro, as respostas autorizadas,
uma síntese do que a família aprendeu e um gesto prático para a semana.

## Endereço

Depois de ativar o GitHub Pages em **Settings → Pages → GitHub Actions**, a página
ficará disponível em:

https://lucastrevvos.github.io/lacos-em-palavras/

## Privacidade

Somente respostas autorizadas pela família devem ser publicadas.
